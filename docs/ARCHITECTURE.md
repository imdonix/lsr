# LOS SANTOS RISING — architecture notes

Run: `node server.js 8080` then open http://localhost:8080/ . No build step. Three.js r186 (vendored in `lib/`).
Conventions (axes, yaw, units, map format) are in `docs/SPEC.md` — read that first.
Global registry: `import { G } from './state.js'` (G.world, G.player, G.peds, G.vehicles, G.map, G.camera, G.hud, G.audio, G.police, ...).
`window.game` / `window.G` are exposed for tests.

## Module map (src/)
| file | role |
|---|---|
| main.js / game.js | boot, loading screen, main loop (`Game.frame`/`Game.sim`), title/play/dead/busted states, save/load, respawn |
| mapdata.js | loads `assets/map.png|zones.png|height.png|districts.json`; classifies pixels; distance field; **road graph** extracted from road pixels by skeletonisation (`map.nodes`, `map.edges`, `map.nearestRoad`) |
| terrain.js | heightfield (`groundY(x,z)` matches the rendered mesh exactly), 128 m chunk meshes, procedurally painted ground textures incl. roads/markings/crosswalks |
| placement.js | procedural city: buildings (frontage + infill), landmarks (`G.landmarks`), props, traffic-signal list, static colliders |
| world.js | chunk streaming (terrain+buildings+props merged per chunk), water plane, static collision (`pushCircle`, `raycast`), prop mesh rebuilds |
| buildings.js | procedural building geometry + facade atlas (generated by a helper worker) |
| models_vehicles.js / models_props.js / models_peds.js / models_weapons.js | procedural low-poly models + animation rigs |
| ragdoll.js | verlet ragdolls for peds (run-over / combat stun / death): 16 particles + distance constraints driving the rig joints directly |
| sky.js | time of day, sun/moon light, sky dome, clouds, fog, weather (rain/smog/cloudy) |
| fx.js | instanced particle pools (smoke/fire/explosions/sparks/blood), tracers, flash lights, rain |
| lights.js | night extras: street-lamp pools, headlight beams, player spotlight, dynamic traffic-signal meshes |
| vehicles.js | `Vehicle` arcade physics + damage + fire/explosion, `VehicleManager`, vehicle-vehicle collisions |
| driverai.js | `DriverAI`: lane-following traffic with signals, chase, flee, follow, goto (A* routes via roadnav.js) |
| roadnav.js | A* over road graph, lane geometry, traffic-light state (`lightState`) |
| peds.js | `Ped` (physics, inventory, damage, vehicle enter/exit), AI brains (civ/gang/cop/ally/script), `PedManager` |
| player.js | `Player extends Ped`: input → movement/aim/weapons/vehicle driving, cheats |
| weapons.js | weapon table, `Combat` (hitscan trace, melee, projectiles, explosions, fire, noise) |
| police.js | wanted level, crime hooks, police cars/cops/roadblocks/heli, arrests |
| population.js | ambient traffic / pedestrian / gang spawning + culling around the player |
| pickups.js | pickups, knockable props, world markers (`G.markers`), radar blips (`G.blips`) |
| places.js | shops: food joints, Ammu-Nation **weapon-dealer NPCs**, **drive-in Pay 'n' Spray garages** (roller-door animation + respray sequence), **safehouse save icon**; each uses the interaction prompt |
| interactions.js | generic "press E to interact" registry + prompt (`G.interactPrompt`) for dealers, the save icon, etc. |
| activities.js | spray tags, taxi duty, vigilante duty |
| missions.js + story.js + story2.js + story4.js + storylib.js | async mission runner + the 24-mission story (Chapters I & II) |
| lifebrain.js / ambient.js / ambient_scenes.js / events_world.js | pedestrian activities, ambient scenes (bus stops, beach, clubs...), 8 random world events |
| story3.js | 4 optional side quests (export list, store protection, gym brawl, street medic) |
| setpieces.js | Vinewood sign, pier + Ferris wheel, airport planes, dock cranes |
| hud.js / menus.js / input.js / camera.js | UI, menus, input abstraction, chase/aim/cutscene camera |
| audio.js | fully procedural WebAudio: SFX, engines, ambience, 5 generative radio stations |

## Main loop
`Game.frame(dt)`: `sim` sub-steps (≤ 20 ms each) → camera → sky → world streaming → fx → audio → HUD → render.
`Game.sim(dt)`: nav → peds (player included) → vehicles → combat → police → population → pickups/markers/props → missions → places → activities.

## Testing tools (tools/)
* `node server.js 8080 &` must be running.
* `node tools/play.js steps.js` — headless Chromium driver; steps.js exports `async (ctx)`; `ctx.eval(fn)`, `ctx.step(seconds)` (fast sim), `ctx.shot(name)` (PNG into scratchpad), `ctx.wait(ms)`.
* `node tools/bot.js --only m05` / `--from m01 --to m24` — auto-plays the story with cheats to detect script errors.
* `tools/make_map.py` regenerates the map images (Python + Pillow).
