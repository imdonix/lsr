# LOS SANTOS RISING — shared technical spec

Browser game, vanilla ES modules + three.js r186 (no bundler, no build step).
Served statically (`node server.js 8080`). Import map in index.html:
`"three" -> ./lib/three.module.js`, `"three/addons/" -> ./lib/addons/` (only `utils/BufferGeometryUtils.js`
and `utils/SkeletonUtils.js` are vendored there; do not assume other addons exist).
No network at runtime: everything (textures, audio, models, music) is procedural or generated by a script.

## Conventions (EVERYONE must follow)
* Units: metres, seconds, radians. Three.js Y is up.
* World axes: +X = east, +Z = south, **north = -Z**. Map image top = north.
* Map image: 1024x1024 px, **2 m per px**, image centre = world origin:
  `worldX = (px - 512) * 2`, `worldZ = (py - 512) * 2` (px,py are pixel centres +0.5 if you care).
  So the world spans x,z in [-1024, 1024].
* Sea level is y = 0. Land is >= +0.8 m, sea floor goes down to about -8 m offshore.
* Heading / yaw convention: object faces local **+Z**; `group.rotation.y = yaw` so forward vector is
  `(sin(yaw), 0, cos(yaw))`. **Facing +Z, left is +X and right is -X** (right-handed, three.js).
  All models (cars, peds, weapons) are authored facing local +Z, origin at ground level between the wheels/feet.
* Left-hand-drive country (USA): driver seat is on the LEFT (+X side), traffic drives on the RIGHT.
* Materials: use MeshLambertMaterial or MeshPhongMaterial (cheap), `vertexColors` + merged geometry for static stuff.
  Share materials/geometries (cache them) — scenes will hold hundreds of objects. Keep triangle counts low-poly
  (San Andreas-style low poly but clean, nicely proportioned, saturated colours, no PBR / no textures files).
* Canvas-generated textures are fine (e.g. windows). No external asset files. No network.
* Do not touch files that are not yours. Put test pages under `tools/` (they can import `../src/...`).
* Test with the headless harness: start server `node server.js 8080` (may already be running — check with
  `curl -s localhost:8080/tools/test.html | head -1`), then
  `node tools/shot.js http://localhost:8080/tools/yourtest.html out.png --wait 3000` (prints console errors, saves screenshot;
  view the PNG with the Read tool to check visuals). Use scratchpad/tmp dirs for screenshots, not the project dir.
  Headless WebGL is software-rendered (slow) — keep test scenes small.

## Map image format (`assets/map.png`, `assets/zones.png`, `assets/height.png`, `assets/districts.json`)
All 1024x1024 PNG, flat colours, **no antialiasing** (classification is nearest-exact-colour).

`map.png` RGB classes:
| class | RGB |
|---|---|
| WATER | (24,70,130) |
| SAND (beach) | (226,208,158) |
| GRASS (parks, lawns, golf, cemetery) | (84,138,66) |
| SCRUB (dry hills, dirt) | (150,132,88) |
| LAND (generic urban ground / lots) | (150,150,146) |
| CONCRETE (river channel bed, airport apron, dock yards, stadium car parks) | (196,196,190) |
| ROAD_STREET (2 lanes, 5 px = 10 m wide) | (255,255,255) |
| ROAD_AVENUE (4 lanes, 8 px = 16 m wide) | (255,240,120) |
| ROAD_FREEWAY (6 lanes + median, 12 px = 24 m wide) | (255,150,50) |
| RUNWAY / taxiway (airport) | (60,60,70) |
Roads are drawn as constant-width polylines (curves = many short segments), ends/junctions at proper points,
always connected into ONE network (no isolated road islands except airport runways). Roads never run
through water. Adjacent parallel roads must be >= 30 px apart (centre to centre) except at junction fan-outs.

`zones.png` per-pixel: **R = zone type**, **G = district id (1..255, 0 = none)**, **B = gang territory id**.
Zone type ids: 0 none/water, 1 RESIDENTIAL_LOW (small houses), 2 RESIDENTIAL_MID (apartments, duplexes),
3 COMMERCIAL (shops, strips, offices low/mid-rise), 4 DOWNTOWN (skyscrapers), 5 INDUSTRIAL (warehouses),
6 BEACH (beach houses, boardwalk), 7 RICH (hillside villas/mansions), 8 PARK (trees, no buildings),
9 AIRPORT, 10 DOCKS (containers, cranes, warehouses), 11 STADIUM/PARKING (open concrete, no generic buildings),
12 WILD (scrub hills, few trees, no buildings), 13 CEMETERY.
Gang id (B): 0 neutral, 1 Emerald Row (player's crew, green), 2 Violet Kings (purple), 3 Los Soles (yellow),
4 Blue Line (blue). Roads carry the zone of the land next to them.

`height.png`: height in metres = `((R*256 + G) / 256) - 20` (range -20 .. +235 m). B = 0, A = 255.
Must be smooth (no stair-stepping: use blurred fields), so cars can drive on it.
Flat (0.8 .. 3 m) over the city basin; beaches ramp gently into the sea; hills in the north (Vinewood Hills /
Mulholland, up to ~90 m) with roads curving up them at max ~12 % grade; a few low rolling hills elsewhere
(Las Colinas, Richman, Verdant Bluffs at the west ~20-30 m). Roads are smooth along their direction
(flatten the heightfield around the road centrelines before blur so there are no bumps). Airport, docks,
stadium area perfectly flat.

`districts.json`: `{ "districts":[{ "id":1,"name":"Ganton","zone":1,"gang":1,"cx":..,"cy":.. (px), "note":"" },...] }`
matching the G channel ids. Use these Los Santos district names (approximate real positions, north up):
Richman, Mulholland, Vinewood, Vinewood Hills, Temple, Rodeo, Market, Commerce, Pershing Square (downtown core),
Downtown Financial, Conference Center, Little Mexico, Jefferson, Glen Park, Las Colinas, East Los Santos,
Los Flores, East Beach, Ganton (gang 1), Idlewood (gang 2), Willowfield (gang 3), El Corona (gang 3),
Playa del Seville, Ocean Flats, Ocean Docks, Los Santos Airport ("LS International"), Santa Maria Beach,
Verona Beach, Verdant Bluffs, Las Brisas?, Jefferson (gang 2), East LS (gang 4), Los Santos Stadium. You may add more.

## Module APIs

### src/audio.js (worker: AUDIO)
```js
export class GameAudio {
  constructor();
  init();                 // create AudioContext (call from a user gesture); safe to call twice; resume() if suspended
  get ready();            // bool
  setVolumes({master, sfx, music});                     // 0..1 each
  update(dt, listener);   // listener = {x,y,z,yaw} (yaw as per convention); updates panning/attenuation of live 3D sounds
  play(name, {pos:{x,y,z}|null, volume=1, pitch=1}={});  // one-shot. pos -> distance attenuation + stereo pan. returns nothing
  loop(name, {pos, volume=1, pitch=1}={}) -> handle {setVolume(v), setPitch(p), setPos({x,y,z}), stop()}  // looped sfx
  engine(kind) -> handle {update(rpm01, throttle01, pos), setVolume(v), stop()}   // kind: 'car'|'truck'|'bike'|'sport'|'heli'
  radio: { stations: [{id,name,genre,desc}], current: -1, set(i) (-1 = off), next(), prev(), setDuck(0..1), nowPlaying() -> string }
  ambient: setAmbient({night01, rain01, crowd01, traffic01, wind01, sea01})  // called each ~0.5s; fades ambience beds
  stopAll();
}
```
One-shot names that MUST exist (others are optional extras): `shot_pistol shot_deagle shot_shotgun shot_smg shot_ak shot_sniper
shot_rpg explosion explosion_small punch kick swing_bat hit_flesh hit_bat hit_body_fall reload cock empty_click pickup cash
mission_pass mission_fail wasted busted phone_ring footstep_concrete footstep_grass footstep_sand splash horn (short beep, pitch-able)
car_hit_light car_hit_heavy glass_break door_open door_close screech scream_male scream_female spray menu_click menu_move
wanted_up grenade_bounce fire_whoosh bullet_whiz bullet_impact ricochet heli_chop cop_whistle siren_short ding`
Loops: `siren_police siren_ambulance tire_skid wind fire_crackle rain water_lap heli_rotor spraycan`.
Everything is synthesised with WebAudio (noise buffers, oscillators, filters, envelopes, convolution/delay). Radio: 5 stations
of **generative music** scheduled with a look-ahead step sequencer (proper drum machine, bass, chords, lead, per-station
chord progressions/tempo/instrument design that sounds musical & distinct, slowly evolving variation so it does not loop
obviously), plus short jingle/station-ident blips when switching. Stations (names are fixed):
0 "Radio Los Santos" (90s G-funk/west-coast hip-hop: ~92 bpm, swung hats, fat sine/saw sub bass, whiny portamento lead),
1 "Sunset FM" (80s synthwave/pop, ~110 bpm, arpeggios, gated pads), 2 "Desert Rock 99.1" (classic rock: distorted power chords,
~124 bpm), 3 "Bounce FM" (funk/disco, ~112 bpm, slap-like bass, stabs), 4 "Tropicana" (latin/salsa-ish, ~100 bpm, congas, marimba-like).
Performance: create nodes sparingly, cap simultaneous voices (e.g. <= 32), reuse noise buffers.

### src/models_vehicles.js (worker: VEHICLES) 
```js
export const VEHICLE_DEFS = { sedan:{name,length,width,height,wheelRadius,wheelbase,track,seats,kind}, ... }  // see type list
export function createVehicleModel(type, colors={body:0xcc2222, secondary:null}) -> VehicleModel
VehicleModel = {
  group: THREE.Group,            // facing +Z, origin on ground centre (between axles, at wheel-bottom height)
  def: VEHICLE_DEFS[type],
  wheels: [{pivot:Object3D (yaw for steering), spin:Object3D (rolls about X), pos:Vector3 (local centre), radius, steer:bool, drive:bool}], // order FL,FR,RL,RR (bike: front,rear)
  seats: [{x,y,z}],              // local seat positions, [0]=driver (LEFT = +X), others passengers; bike: [rider, pillion]
  setBrake(on), setHeadlights(on), setReverse(on), setSiren(on), setIndicators(-1|0|1)(optional),
  setBodyColor(hex), setDamage(0..1) (progressive visual: darken/scuff, crumple-ish offsets, broken glass tint), setBurnt(bool),
  update(dt)                     // siren lightbar animation etc.
  dispose()
}
```
Types (length x width x height in m): sedan 4.8x1.85x1.45, coupe 4.4x1.8x1.3, muscle 4.9x1.95x1.3, lowrider 5.2x1.9x1.4
(long classic with low stance), sports 4.3x1.9x1.15, hatch 3.8x1.7x1.5, suv 4.6x1.95x1.85, pickup 5.2x1.9x1.75,
van 5.2x2.0x2.2, taxi (sedan + roof sign, yellow), police (sedan, black/white, roof lightbar with red/blue flashing),
swatvan 5.6x2.1x2.3 (black armoured van), ambulance 5.6x2.1x2.4, bus 11x2.6x3.1, truck (box truck) 7x2.4x3.2,
limo 7.5x2.0x1.5, motorbike 2.1x0.8x1.2 (leaning is done by the engine by rotating group), bicycle 1.7x0.6x1.0,
policeheli 12x3x3.4 (fuselage + main rotor and tail rotor spinning in update(); wheels = []; `setSiren` toggles a searchlight beam).
Each car: body shell with believable silhouette (side profile polygon extruded, bevelled/tapered, separate glass,
bumpers, grille, headlights + tail lights (emissive when on), wheels with rims/tyres, exhaust, mirrors, door lines, plates).
Rear/brake light emissive boost on setBrake; headlight beams at night are added by the engine (not your job).
